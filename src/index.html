§ 00

什么是 Claude Code？

Claude Code 是 Anthropic 官方推出的命令行 AI 编程助手，核心理念是"住在终端里"。它能理解项目结构、编辑代码、执行 Shell 命令、管理 Git，并通过 MCP 协议与数百个外部服务集成。

🗂️
理解代码库
分析整个项目结构，跨文件维护上下文，理解依赖关系
✏️
直接编辑文件
直接读写项目文件，支持多文件重构、代码生成与修复
⚡
执行终端命令
运行测试、构建、Git 操作等，与你的开发流程无缝融合
🔌
MCP 生态集成
通过 MCP 协议连接 GitHub、数据库、Slack 等 300+ 外部服务
ℹ️
Claude Code 支持接入任何兼容 Anthropic API 格式的模型，包括 DeepSeek、通义千问、Kimi、GLM、豆包等国产大模型，以及 AWS Bedrock、Google Vertex AI 等国际云平台。

安装 Claude Code

前置条件

依赖项要求安装命令
Node.js版本 ≥ 18.0（推荐 LTS）node --version 检查
npm随 Node.js 一起安装npm --version 检查
操作系统macOS / Linux / Windows (WSL2 推荐)—
网络可访问 npm registry 即可国内可换淘宝镜像

安装命令

bash · 全局安装
# 全局安装（推荐）
npm install -g @anthropic-ai/claude-code

# 国内用户可先换镜像加速
npm config set registry https://registry.npmmirror.com
npm install -g @anthropic-ai/claude-code

# 安装后验证版本
claude --version
⚠️
Windows 用户注意：建议安装 WSL2（Windows Subsystem for Linux）后在 Linux 环境中使用，以获得最佳兼容性。若使用 CMD/PowerShell，环境变量设置方式有所不同（见下文）。

Node.js 安装（如未安装）

bash · Node.js 安装
# macOS（推荐用 Homebrew）
brew install node

# Ubuntu / Debian Linux
curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -
sudo apt-get install -y nodejs

# 也可访问 https://nodejs.org 直接下载 LTS 安装包
§ 02

官方 Anthropic API 配置

使用官方 Anthropic API 需要订阅 Claude Pro/Max，或直接购买 API 额度（在 console.anthropic.com 获取 API Key）。

获取 API Key

1
注册 / 登录 Anthropic Console
访问 console.anthropic.com，注册账号并完成验证
2
创建 API Key
进入 Settings → API Keys → Create Key，保存好密钥（只显示一次）
3
配置环境变量
将 API Key 设置为环境变量，或使用 claude 命令交互登录

配置方式

macOS / Linux
Windows PowerShell
Windows CMD
# 临时生效（当前终端会话）
export ANTHROPIC_API_KEY="sk-ant-your-api-key-here"

# 永久生效 - zsh（macOS 默认）
echo 'export ANTHROPIC_API_KEY="sk-ant-your-api-key-here"' >> ~/.zshrc
source ~/.zshrc

# 永久生效 - bash（Linux 默认）
echo 'export ANTHROPIC_API_KEY="sk-ant-your-api-key-here"' >> ~/.bashrc
source ~/.bashrc

# 启动 Claude Code
claude
# 临时生效（当前 PowerShell 会话）
$env:ANTHROPIC_API_KEY = "sk-ant-your-api-key-here"

# 永久生效（用户级别）
[Environment]::SetEnvironmentVariable("ANTHROPIC_API_KEY", "sk-ant-your-api-key-here", [EnvironmentVariableTarget]::User)

# 永久生效（快捷方式）
setx ANTHROPIC_API_KEY "sk-ant-your-api-key-here"

# 重新打开终端后验证
claude
:: 临时生效
set ANTHROPIC_API_KEY=sk-ant-your-api-key-here

:: 永久生效（需重新打开 CMD）
setx ANTHROPIC_API_KEY "sk-ant-your-api-key-here"

:: 启动
claude

交互式登录（推荐新手）

bash
# 直接启动，首次会引导登录
claude

# 或使用登录命令
claude /login

§ 03

接入国产大模型

Claude Code 支持通过修改 ANTHROPIC_BASE_URL 环境变量，将请求转发到兼容 Anthropic API 格式的国产模型平台。以下是主流国产平台的完整配置。

💡
核心原理：只要目标平台的 API 兼容 Anthropic 协议格式（即支持 /v1/messages 接口），就可以通过修改 BASE_URL 直接接入，无需任何中间件。

🔷 DeepSeek（深度求索）

DeepSeek 官方已原生支持 Anthropic API 格式，是目前对 Claude Code 兼容性最好的国产平台之一。

bash · DeepSeek 配置
export ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic
export ANTHROPIC_AUTH_TOKEN="your_deepseek_api_key"
export ANTHROPIC_MODEL="deepseek-chat"           # DeepSeek V3（通用编码）
export ANTHROPIC_SMALL_FAST_MODEL="deepseek-chat"
export API_TIMEOUT_MS=600000                    # 10分钟超时，防止长输出中断
export CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1

# 如需使用推理模型（R1 系列）
# export ANTHROPIC_MODEL="deepseek-reasoner"

获取 API Key： platform.deepseek.com → API Keys → 创建密钥

🟠 通义千问（阿里云百炼）

阿里云百炼平台提供 Qwen 系列模型的 Anthropic API 兼容接口，包括专为编程优化的 qwen3-coder-plus。

bash · 通义千问配置（按量付费）
export ANTHROPIC_BASE_URL=https://dashscope.aliyuncs.com/apps/anthropic
export ANTHROPIC_API_KEY="your_dashscope_api_key"
export ANTHROPIC_MODEL="qwen3-coder-plus"       # 编程专用旗舰
# 其他可选模型：qwen3-max / qwen3.5-plus / qwen-coder-turbo
bash · 通义千问（Coding Plan 套餐专用）
export ANTHROPIC_BASE_URL=https://coding.dashscope.aliyuncs.com/apps/anthropic
export ANTHROPIC_AUTH_TOKEN="coding_plan_exclusive_api_key"
export ANTHROPIC_MODEL="qwen3-coder-plus"

获取 API Key： bailian.console.aliyun.com → API Key 管理

🌙 Kimi（Moonshot AI）

bash · Kimi 配置
export ANTHROPIC_BASE_URL=https://api.moonshot.cn/anthropic
export ANTHROPIC_AUTH_TOKEN="your_kimi_api_key"
export ANTHROPIC_MODEL="kimi-k2-turbo-preview"  # 或 moonshot-v1-32k
export ANTHROPIC_SMALL_FAST_MODEL="kimi-k2-turbo-preview"

获取 API Key： platform.moonshot.cn → API 密钥

🧠 智谱 GLM（ChatGLM）

bash · 智谱 GLM 配置
# 国内版
export ANTHROPIC_BASE_URL=https://open.bigmodel.cn/api/anthropic
# 国际版
# export ANTHROPIC_BASE_URL=https://api.z.ai/api/anthropic
export ANTHROPIC_AUTH_TOKEN="your_zhipu_api_key"
export ANTHROPIC_DEFAULT_HAIKU_MODEL="glm-4.5-air"  # 快速模型
export ANTHROPIC_DEFAULT_SONNET_MODEL="glm-4.6"     # 主力模型
export ANTHROPIC_DEFAULT_OPUS_MODEL="glm-4.6"
export API_TIMEOUT_MS=3000000

获取 API Key： open.bigmodel.cn → 控制台 → API Keys

🫘 豆包（字节跳动火山方舟）

bash · 豆包配置（需开通 Code Plan）
export ANTHROPIC_BASE_URL=https://ark.cn-beijing.volces.com/api/coding

🤗 魔搭社区（ModelScope）

魔搭提供 Qwen 和 DeepSeek 等模型的免费 API（每天 2000 次），适合学习体验。

bash · 魔搭社区配置

bash · AWS Bedrock 配置
export CLAUDE_CODE_USE_BEDROCK=1
export AWS_ACCESS_KEY_ID="your_access_key"
export AWS_SECRET_ACCESS_KEY="your_secret_key"

# 或使用 Bearer Token（跳过 AWS 认证，用于网关场景）
# export CLAUDE_CODE_SKIP_BEDROCK_AUTH=1
# export AWS_BEARER_TOKEN_BEDROCK="your_token"

🔶 Google Vertex AI

bash · Google Vertex AI 配置
export CLAUDE_CODE_USE_VERTEX=1
export VERTEX_PROJECT_ID="your-gcp-project-id"
export VERTEX_REGION="us-east5"
# 确保已通过 gcloud auth application-default login 认证

🔵 Microsoft Azure Foundry

bash · Microsoft Foundry 配置
export CLAUDE_CODE_USE_FOUNDRY=1
export ANTHROPIC_FOUNDRY_RESOURCE="your-resource-name"
# BASE_URL 格式: https://<resource-name>.services.ai.azure.com
# Claude Code 会自动在末尾追加 /anthropic

🔀 LiteLLM Proxy（统一路由，支持任意模型）

LiteLLM 是一个统一代理，可以将 Claude Code 的请求路由到 GPT-4、Gemini、Mistral 等任意模型。

bash · LiteLLM 安装与配置
# 安装 LiteLLM
pip install litellm[proxy]

# 创建 litellm_config.yaml（示例）
cat > litellm_config.yaml << 'EOF'
model_list:
  - model_name: claude-sonnet-4-6
    litellm_params:
      model: anthropic/claude-sonnet-4-6
      api_key: sk-ant-xxx
  - model_name: gpt-4o
    litellm_params:
      model: openai/gpt-4o
      api_key: sk-openai-xxx
  - model_name: gemini-2.5-pro
    litellm_params:
      model: gemini/gemini-2.5-pro
      api_key: gemini-xxx
EOF

# 启动 LiteLLM 代理（默认端口 4000）
litellm --config litellm_config.yaml

# 配置 Claude Code 指向 LiteLLM
export ANTHROPIC_BASE_URL=http://0.0.0.0:4000
export ANTHROPIC_AUTH_TOKEN="your_litellm_master_key"

🌐 OpenRouter（访问 100+ 模型）

bash · OpenRouter 配置

§ 05

配置文件详解

除环境变量外，Claude Code 支持通过 JSON 配置文件进行持久化配置，优先级高于环境变量。

配置文件位置

配置文件作用范围说明
~/.claude/settings.json 全局（所有项目） 用户级全局配置，适合存放 API Key 等通用设置
.claude/settings.json 当前项目 项目级配置，可提交到 Git（注意不要包含 API Key）
.claude/settings.local.json 当前项目（本地） 本地覆盖，不应提交到 Git，适合个人 API Key

完整配置文件示例

json · ~/.claude/settings.json
{
  "env": {
    // API 认证（二选一：ANTHROPIC_API_KEY 或 ANTHROPIC_AUTH_TOKEN）
    "ANTHROPIC_AUTH_TOKEN": "your_api_key_here",
    "ANTHROPIC_BASE_URL": "https://api.deepseek.com/anthropic",

    // 模型配置
    "ANTHROPIC_MODEL": "deepseek-chat",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "deepseek-reasoner",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "deepseek-chat",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "deepseek-chat",
    "CLAUDE_CODE_SUBAGENT_MODEL": "deepseek-chat",

    // 性能与限制
    "API_TIMEOUT_MS": "600000",
    "CLAUDE_CODE_MAX_OUTPUT_TOKENS": "32000",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1"
  },
  "permissions": {
    // 允许的操作（留空则每次询问）
    "allow": [
      "Bash(git:*)",
      "Bash(npm:*)",
      "Bash(python:*)"
    ],
    // 拒绝的危险操作
    "deny": [
      "Bash(rm -rf *)"
    ]
  },
  "alwaysThinkingEnabled": false
}

环境变量参考

变量名说明示例值
ANTHROPIC_API_KEYAPI 认证密钥（标准方式）sk-ant-xxx 或各平台的 key
ANTHROPIC_AUTH_TOKENAPI 认证（替代方式，与上面任选其一）同上
ANTHROPIC_BASE_URLAPI 端点地址https://api.deepseek.com/anthropic
ANTHROPIC_MODEL主要使用的模型deepseek-chat / qwen3-coder-plus
ANTHROPIC_DEFAULT_OPUS_MODEL复杂任务使用的模型deepseek-reasoner
ANTHROPIC_DEFAULT_SONNET_MODEL普通任务使用的模型deepseek-chat
ANTHROPIC_DEFAULT_HAIKU_MODEL快速/轻量任务模型glm-4.5-air
ANTHROPIC_SMALL_FAST_MODEL辅助快速模型（背景任务）deepseek-chat
CLAUDE_CODE_SUBAGENT_MODEL子代理使用的模型deepseek-chat
API_TIMEOUT_MS请求超时（毫秒）600000（10 分钟）
CLAUDE_CODE_MAX_OUTPUT_TOKENS最大输出 token 数32000
CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC禁用非必要网络请求（省流）1

CLAUDE.md — 项目上下文文件

Claude Code 会自动读取项目根目录的 CLAUDE.md 文件，将其作为每次对话的系统上下文。这是传递项目信息的最佳方式。

markdown · CLAUDE.md 示例
# 项目上下文

## 技术栈
- 前端：React 18 + TypeScript + Tailwind CSS
- 后端：FastAPI + PostgreSQL + Redis
- 部署：Docker + Kubernetes

## 常用命令
- `npm run dev`     启动开发服务器
- `npm test`        运行测试
- `npm run build`   生产构建

## 代码规范
- 使用 TypeScript 严格模式
- 所有函数必须有 JSDoc 注释
- 新代码必须配有单元测试

## 目录结构
- src/components/   React 组件
- src/api/          API 调用层
- src/utils/        工具函数

MCP 插件扩展

MCP（Model Context Protocol）是 Claude Code 的插件系统，可接入 GitHub、数据库、Slack 等 300+ 外部服务。

添加 MCP 服务器

bash · MCP 管理命令
# 交互式添加（推荐新手）
claude mcp add

# 直接添加命令行 MCP 服务器
claude mcp add my-server /path/to/mcp-server

# 常见 MCP 服务器安装示例
claude mcp add github -- npx @modelcontextprotocol/server-github
claude mcp add postgres -- npx @modelcontextprotocol/server-postgres postgresql://localhost/mydb
claude mcp add filesystem -- npx @modelcontextprotocol/server-filesystem /path/to/dir

配置文件中添加 MCP

json · ~/.claude/settings.json 中的 MCP 配置
{
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": {
        "GITHUB_PERSONAL_ACCESS_TOKEN": "ghp_your_token"
      }
    },
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/your/project/path"]
    }
  }
}

使用技巧与最佳实践

降低 Token 消耗

🎯
精确指令
提出明确、具体的请求，避免模糊表达触发大量文件扫描

压缩上下文
长会话使用 /compact 自动摘要历史对话

国内用户常见问题

❌
连接错误："Unable to connect to Anthropic services" — 这是因为 Claude Code 默认连接官方 API，在国内无法访问。解决方案：配置 ANTHROPIC_BASE_URL 指向国内兼容平台（见第 §03 节）。
⚠️
注意：Windows 用临时 $env:xxx 设置的环境变量只在当前终端有效，重新打开终端会失效。推荐使用 setx 命令永久写入，或使用 .claude/settings.json 配置文件。

快速切换模型配置

bash · 在 ~/.zshrc 中定义切换函数
# 切换到 DeepSeek
function use-deepseek() {
  export ANTHROPIC_BASE_URL="https://api.deepseek.com/anthropic"
  export ANTHROPIC_AUTH_TOKEN="$DEEPSEEK_API_KEY"
  export ANTHROPIC_MODEL="deepseek-chat"
  echo "✅ 已切换到 DeepSeek"
}

# 切换到通义千问
function use-qwen() {
  export ANTHROPIC_BASE_URL="https://dashscope.aliyuncs.com/apps/anthropic"
  export ANTHROPIC_API_KEY="$DASHSCOPE_API_KEY"
  export ANTHROPIC_MODEL="qwen3-coder-plus"
  echo "✅ 已切换到 Qwen3-Coder"
}

# 切换到官方 Claude（需要 API Key）
function use-claude() {
  unset ANTHROPIC_BASE_URL
  export ANTHROPIC_API_KEY="$CLAUDE_API_KEY"
  unset ANTHROPIC_MODEL
  echo "✅ 已切换到官方 Claude"
}
